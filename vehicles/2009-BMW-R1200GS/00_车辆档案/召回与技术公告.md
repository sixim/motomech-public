# ⚠️ 召回与技术公告 · 2009 R1200GS（hexhead）

> **2026-09-14 重建**：此前本文件按 modelYear=2010 查询。车主提供 VIN
> `YOUR_VIN_HERE`，NHTSA 官方解码器返回 **ModelYear 2009**（校验位通过），
> 按 2009 重查后清单**变了** —— 多出一条致命级的前刹车油管召回。
>
> **年份判错，连该查的召回都查不到。** 这是本项目最贵的一次教训。

> 来源：**NHTSA 官方 API**（A 级）
> `api.nhtsa.gov/recalls/recallsByVehicle?make=bmw&model=R 1200 GS&modelYear=2009`
> ⚠️ 车型名必须写 **"R 1200 GS"（带空格）**；另一种写法 `R1200 GS` 会返回**不同的条目**，
> **两种都要查才全**（20V471000 和 17E052000 只在第二种写法下出现）。

**全部召回由 BMW 免费执行，不因车龄失效。**
BMW 客服：**1-800-525-7417**（报 VIN 查本车执行状态 —— 只有你能做这件事）

## 🔴 10V276000 · 前刹车油管 —— 2009 专有，按 2010 查时完全不出现

| | |
|---|---|
| 范围 | 2007–2009 R 1200 与 K 1200 系列，2006-08 至 2009-05 生产 |
| 原文 | "DUE TO THE CURRENT ROUTING OF THE FRONT BRAKE LINES... THE BRAKE LINE COULD SPLIT AND START TO DEVELOP A LEAK" |
| 后果 | "IF THE BRAKE FLUID RESERVOIR RUNS EMPTY, **THE FRONT BRAKES COULD FAIL**" |
| 处理 | 免费更换带「护套」的新油管 |
| 发布 | 2010-06-18，召回于 2010-09-20 开始 |
| 卡住 | **Phase 6（制动）/ Phase 9（路试）** |

> 作业含义：如果这条还没执行，那么你在 P6 花几小时冲洗的那套管路**本身就是要被换掉的件**。
> 先查执行状态再决定 P6 怎么做。

## 🔴 15V141000 · 后轮安装法兰

| | |
|---|---|
| 范围 | 2005–2010 R1200GS / GS Adventure |
| 后果 | 法兰开裂 → 螺栓松动 → **后轮可能在行驶中脱离** |
| 处理 | 免费更换钢制法兰 |
| 卡住 | **Phase 7 / Phase 9** —— 门禁里是不可解除的 BLOCK，未确认前不得上路 |

## 🔴 13V617000 · 燃油泵法兰

| | |
|---|---|
| 范围 | 2005–2011 R 系 |
| 后果 | 法兰开裂漏油 → 起火 |
| 卡住 | **Phase 4** |

## 🔴 20V471000 · 燃油泵（13V617 的后续）

| | |
|---|---|
| 范围 | 含 **2005–2011 R1200 (GS, GS Adventure, R, RT, S, ST)** |
| 针对 | 「已按 13V-617 装过支撑环、但泵未更换」的车 |
| 原文 | "fuel pump flange that may crack, possibly resulting in a fuel leak while the engine is running" |
| 说明 | 2021 年发布，本车停放期间必然未执行 |
| 卡住 | **Phase 4** |

## 🟡 17E052000 · 选装转向灯

仅当本车装有 BMW 选装转向灯时适用。P1 拍照时留意灯具是否为原厂件。
