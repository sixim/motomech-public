# 故障模式库 · 2010 R1200GS (camhead / K25)

> 来源：**NHTSA 官方投诉库**（A 级）— 车主实名上报的真实故障，比论坛传闻权威
> `api.nhtsa.gov/complaints/complaintsByVehicle?make=bmw&model=R 1200 GS&modelYear=2010`
>
> ⚠️ **API 两个坑**：`Count` 字段恒报 0（只看它会误判"无投诉"）；
> 车型名必须两种写法都查（`R 1200 GS` 与 `R1200 GS`），否则漏数据。

---

## ① 燃油液位传感器（fuel strip）失效 — 最高频

**8 条投诉中占 4 条。**

| | |
|---|---|
| 症状 | 燃油表失效 / 假读数 / 燃油警告灯乱亮 |
| 后果 | **路上没油**（多起发生在车流中、过路口时） |
| 关键 | 原话 "FUEL STRIP FAILED. **REPLACED AGAIN IN 6/2012**" — **换了还会再坏** |
| 跨度 | 2010–2014 多起 |

**检查项**：Phase 3 通电后，核对燃油表读数与实际油量是否吻合。
**预期**：这是消耗性故障，换新不等于一劳永逸，要有心理准备。

## ② 节气门体塑料件开裂 — camhead 特有的设计退化

**这条是专业店才知道的坑。**

| | |
|---|---|
| 部位 | **节气门拉线固定处的塑料耳** |
| 原话 | "PART ON THROTTLE BODY WHERE THE THROTTLE CABLE ATTACHES **KEEPS ON CRACKING**. IT IS A **PLASTIC PART WHEN ALL PREVIOUS MODELS WERE METAL**. THIS HAS HAPPENED **THREE TIMES** ON MY BIKE" |
| 代际 | **hexhead 是金属件，camhead 改成塑料** → 查 hexhead 资料**发现不了**这个问题 |
| 零件 | **不单卖**："INDIVIDUAL PART IS NOT AVAILABLE" → 必须换整个节气门体 |
| 成本 | 约 $546 零件 + $400 工时 |

**检查项**：Phase 1 静态评估就要看 — 塑料老化十年 + 已知反复开裂 = 高危。
**拍照要求**：节气门拉线固定处特写，侧光看裂纹。

## ③ 燃油泵故障

| | |
|---|---|
| 原话 | "**THE FUEL PUMP SPRAYED FUEL ONTO THE DRIVER**"（启动时喷油到骑手身上） |
| 关联 | 另一起直接引用召回 **20V471000** |

**与三项燃油系统召回互相印证**（13V617000 / 20V471000 见 `召回与技术公告.md`）。
**检查项**：Phase 4 拆油箱前，先问经销商这两条召回的执行状态。

## ④ 变速箱 6 挡跳挡

| | |
|---|---|
| 原话 | "WILL ON OCCASION **POP OUT OF 6TH GEAR** ON THE HIGHWAY" |
| 级别 | **C 级**（单条投诉，样本不足） |

**检查项**：Phase 9 路试时留意高速 6 挡。

## 汇总：本车的高危清单

| 系统 | 问题 | 证据强度 |
|---|---|---|
| 燃油 | fuel strip 失效 · 泵泄漏 · FPC 腐蚀 | **A**（投诉 6 条 + 召回 3 项） |
| 进气 | 节气门体塑料件开裂 | **A**（投诉，camhead 特有） |
| 行走 | 后轮法兰开裂（召回 15V141000） | **A**（NHTSA 召回，致命） |
| 变速 | 6 挡跳挡 | C（单条） |

> **燃油系统是这台车最该盯的地方** — 投诉与召回在此高度重合。
