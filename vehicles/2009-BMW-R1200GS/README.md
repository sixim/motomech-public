## 车辆身份（已核实，决定所有资料选型）

| 项 | 结论 |
|---|---|
| 发动机 | **hexhead**（SOHC，2004–2009）—— 与 2010+ camhead(DOHC) **不是同一台发动机** |
| ECU | BMS-K+ (BMS-KP) |
| 诊断口 | **10 针圆形**，座垫下/电池仓。**不是 OBD-II** |
| ABS | Integral ABS，**非 servo**（2007 后取消助力泵） |
| 电气 | 单线 CAN-bus（ZFE + ECU + ABS + 仪表） |

⚠️ **最大的资料陷阱**：网上大量 R1200GS 教程和常见的 RepROM「K2x」版本只覆盖到 2009。
拿 camhead 资料修 hexhead，气门与点火部分会直接出错（火花塞型号就完全不同）。

---

## ⛔ 三条硬红线

1. **不能直接打火。** 十年的汽油已变质成胶质，直接打火会把胶质泵进喷油嘴
2. **上起动机前必须手动盘车确认能转。** boxer 水平缸油膜早已流失，缸壁可能锈蚀
3. **必须先装新电池再读故障码。** CAN-bus 车亏电会吐出大量假故障码

### ⚠️ Qwen2.5-Omni 使用规则（实测得出，必须遵守）

**它的听力是真的，但顺从性极强 —— 你暗示什么，它就"听到"什么。**

2026-09-12 对照实验，同一段室内打包行李的录音：

| 提示词 | 输出 | 结论 |
|---|---|---|
| 中性："描述你听到的所有声音" | "喷雾罐的声音、揉纸的声音、东西被扔掉的声音" | ✅ 与画面完全吻合 |
| 暗示："这是摩托车发动机录音" | "机械运转的轰鸣声、发动机的咔哒声" | ❌ 画面里根本没有发动机 |

**规则：**
- 提示词**严格中性**，绝不出现"摩托车""发动机""异响""故障"等词
- 已固化进 `tools/omni_listen.py`，不要自行改提示词
- 它的输出是**感知描述**，不是诊断。判断交给 Claude，结合频谱图和工况
- 诊断真异响时如果告诉它"这是异响"，它会附和着编出故障 —— 比没有这个通道更危险

## 数据准确性规则

**所有扭力值、气门间隙、油液容量，只写手册核实过的数字，绝不凭记忆给。**
铝合金件上一个错误的扭力值就是一个滑牙的缸体。
未核实的一律标注「待手册核实」，不要拿去用。
