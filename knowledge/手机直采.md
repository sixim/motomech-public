# 手机直采（Tailscale 直连）

用**手机自己的**摄像头和麦克风采集，经 Tailscale 直接写进车辆档案。

## 为什么走这条路

| 问题 | 这条路怎么解 |
|---|---|
| Mac 摄像头权限被拒（实测 `Camera access not granted`，设备能枚举但抓不了帧） | 用手机的摄像头，权限归 Safari 管，与 Mac 终端授权无关 |
| **录音从来没实现过**（`listen.sh` 只分析已有文件，不采集；两台车音频 0 段） | 浏览器内 `MediaRecorder` 直接录，录完即传 |
| 修车时人在车边、Mac 在工作台 | 手机是唯一拿在手里的设备 |

## 服务已常驻，不用手动起

2026-09-16 起由 launchd 托管，开机自启、崩溃自动拉起（实测 kill -9 后 PID 12045→12087）。

* 配置：`~/Library/LaunchAgents/com.simon.repairbench.serve.plist`
* 二进制：`bin/repairbench`（release 的**稳定副本**）
  —— 刻意不指 `target/release/`：那是构建产物目录，`cargo clean` 会清掉它，
  服务会无声断掉。改了代码要生效，得重新 `cp` 一次：

  ```bash
  cargo build --release --manifest-path "$HOME/Ai Developer/AI+摩托维修助理/repairbench/src-tauri/Cargo.toml" && cp "$HOME/Ai Developer/AI+摩托维修助理/repairbench/src-tauri/target/release/repairbench" "$HOME/Ai Developer/AI+摩托维修助理/bin/repairbench" && launchctl kickstart -k gui/$(id -u)/com.simon.repairbench.serve
  ```

* 日志：`logs/serve.out.log` / `logs/serve.err.log`
* 停：`launchctl unload ~/Library/LaunchAgents/com.simon.repairbench.serve.plist`
* 起：把 `unload` 换成 `load`

Tailscale 代理也已配好（一次性，常驻）：

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg 8765
```

它把本机回环的 8765 代理成
`https://YOUR-MACHINE.YOUR-TAILNET.ts.net/`，**仅 tailnet 内可达**。

手机上打开：`https://YOUR-MACHINE.YOUR-TAILNET.ts.net/capture`

关掉代理：`tailscale serve --https=443 off`

## 为什么必须走 https（不是为了好看）

iOS Safari 的 `getUserMedia`（浏览器内录音）**要求安全上下文**，纯 http 直接不给用。
`tailscale serve` 给的是真 Let's Encrypt 证书（`*.ts.net`），所以录音才能用。
拍照走 `<input capture>`，http 下也能用 —— 但录音不行。

## 安全边界（三层）

1. **进程只绑 127.0.0.1**（`serve` 默认值，不要改成 0.0.0.0）。
   对外暴露完全交给 Tailscale，本程序不自己发明认证。
2. **访问控制 = Tailscale ACL**。用 `serve` 不是 `funnel` —— funnel 会开到公网。
3. **来源 IP 仍然要查**：只接受回环与 100.64.0.0/10。纵深防御，
   万一有人把 `--host` 改了也不至于门户大开。

**文件名一个字都不信**：上传方给的文件名可能带路径或 `..`，
所以扩展名走白名单、文件名由程序生成（沿用 snap.sh 的
`YYYYMMDD_阶段_标签_phone_序号.ext`，和翻拍台的照片在同一命名空间）。
实测 `../../../etc/evil.sh` 被拒。

## 文件落在哪

| 类型 | 目录 | 说明 |
|---|---|---|
| 图片 jpg/jpeg/png/heic | `vehicles/<车>/60_影像/inbox/` | 索引器就 walk 这里 |
| 音频 m4a/mp3/wav/aac/caf/webm/ogg | `vehicles/<车>/60_影像/音频/` | 索引器按扩展名过滤，不会被误算成照片（实测照片计数仍是 6） |

浏览器内录音产生的是 Blob，**没有扩展名** —— 服务端按 MIME 判类型，实测可用。
